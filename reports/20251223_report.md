# Nurse Rostering Team Project


## Achievements


We have set up a project structure which integrates the essences of chapter 12 and 13 of the CP-SAT Primer. This integration contains an implementation of an API interface and a basic solver structure.
In addition we have applied for Hexaly license and took a quick dive into the difference in syntax of Hexaly and already known (to us) solvers.
Also we have set up some plans for extending the solver and the underlying data schema to the description of the nurse rostering problem in [Computational results on new staff scheduling benchmark instances](https://www.schedulingbenchmarks.org/papers/computational_results_on_new_staff_scheduling_benchmark_instances.pdf).
We have also set up communication via WhatsApp and Discord and discussed a rostering which fits all our holiday constraints.
